# GI expression and mammalian lifespan: final artifact guide

This directory is the entry point for reproducing the experiment and building reports or presentations. The outcome is **recorded maximum species lifespan in years**, not an individual's age or average life expectancy. Expression is **GI-predicted log(TPM+1)** from genomic sequence, not measured RNA abundance.

## Findings to carry into reports

1. **30 significant raw Spearman associations** were found in the frozen 2,001-gene snapshot (63,906 observations), using 999,999 permutations per gene and BH correction over 3,036 planned tests. No ancestry or body-mass correction was used. The snapshot is preserved even though the full run subsequently completed.
2. **Only six genes were shuffled:** ABHD4, TDO2, CCDC85A, LGI1, ACSS1 and ATG14. Ten independent 8-bp block permutations were made per species in ±4,096 bp around the TSS. The other 24 original hits were not perturbed. All six correlations weakened; none of the shuffled-mean associations passes BH q < 0.05 across the six genes. This supports local sequence sensitivity, while causal effects on lifespan remain untested.
3. **The regressors show comparative predictive signal but underpredict human longevity.** They were trained without human lifespan, using the completed dataset and nested nonhuman validation. The 57 selected regression genes are a separate training-only screen, not the original 30-hit list.

| Regression | Fitted genes | Human prediction, years | Nonhuman nested-validation MAE, years |
|---|---:|---:|---:|
| Selected-gene ridge | 57 | **32.5275** | 12.8482 |
| All-gene ridge | 3,036 | **46.5556** | 10.3328 |
| Geometric-mean baseline | 0 | 22.3379 | 14.9626 |

The human reference is **GRCh38, Ensembl release 116**. Its AnAge recorded maximum lifespan is **122.5 years**. Human lifespan was excluded from gene selection, imputation/scaling, tuning and fitting. Human has 56/57 selected features and 3,034/3,036 all-gene features; missing values receive the saved training medians. The reference assembly, TSS coordinates, input hashes and missing genes are recorded in [reference provenance](reference_human_provenance.json).

## Reuse conventions

- Join genes by stable `human_gene_id` (human Ensembl ID), not by symbol. Species keys are `ensembl_species`.
- Do not conflate **30** original permutation hits, **six** perturbed candidates, and **57** nonhuman regression features.
- Original-screen q values use **3,036** planned genes. Shuffled-mean q values use **six** already-selected candidates. The native retest has identical rho but independently simulated p values and its own six-gene correction.
- Permutation resolution is 10⁻⁶; p=10⁻⁶ means zero extreme draws with the +1 correction, not a zero p value.
- Ten shuffles per species are technical perturbations. The correlation sample size remains 30–35 species per candidate, not ten times that number.
- The GI context is identical for every species, including the literal name `Homo sapiens`. Species labels in output files never change the API description.
- Report the poor human prediction alongside nonhuman validation performance. These models are not validated estimates of personal life expectancy or causal gene effects.

The artifact manifest records every file's role, size, SHA-256, table dimensions where applicable, and recommended use. Raw genomes, extracted DNA windows, API credentials and the full API cache are external to Git; reference URLs/checksums and compact numeric observations are included.
